# Sheep and surf gameplay references

The user supplied [Throwback - Sheep (2000), PlayStation](https://www.youtube.com/watch?v=eae-p656srQ). The video page could not be retrieved in this session, so no claim is made to have watched it. The [gameplay overview](https://en.wikipedia.org/wiki/Sheep_%28video_game%29) describes choosing a herder and guiding different sheep types through obstacle-filled worlds. This informed indirect control, flock personalities, original route puzzles and clear rescue goals. It does not justify copying the original characters, maps or assets.

For the user's Kelly Slater's Pro Surfer (2002) reference, the [contemporary Nintendo World Report review](https://www.nintendoworldreport.com/review/3969/kelly-slaters-pro-surfer-gamecube) describes wave positioning, linked tricks, a special meter, tube balance and level objectives. The surf redesign interprets these as momentum-based carving, a chasing curl, safe-exit barrel scoring, Special mode, and replayable heats/free practice. It is not a recreation of the complete console game.

The mouse-lock implementation follows the [MDN Pointer Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_Lock_API) model: user-initiated lock, relative movement, loss/change events and a usable unlocked alternative. Browser support and pointer-lock comfort still need real-device checks.
